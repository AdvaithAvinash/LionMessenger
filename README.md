# LionMessenger
🦁 Lion Messenger

A secure private messaging and calling app that works without phone numbers — only email-based authentication.

✨ About

Lion Messenger is a private and secure communication platform designed for users who value privacy and simplicity.

Unlike traditional messaging apps, Lion Messenger allows users to connect using only their email address — no phone number required.

The app provides fast messaging, secure voice/video calling, and a modern communication experience while keeping user data protected.

🚀 Features
💬 Real-time private messaging
📞 Voice calling
🎥 Video calling
🔒 End-to-end encrypted chats
📧 Email-only login & signup
👥 Group chats
📎 Media & file sharing
✅ Read receipts
✍️ Typing indicators
🌙 Dark mode support
☁️ Multi-device sync
🔔 Real-time notifications
👤 Username-based profiles
🔐 Privacy First

Lion Messenger is built with privacy as the core principle.
